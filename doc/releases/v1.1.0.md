# MetricFlowX 1.1.0

## Container image and SDK

- The Linux AMD64 and ARM64 images include both Debug and Release builds of
  MetricFlowX using Trilinos. The installed CMake package provides both
  configurations for downstream applications, including ImmersX.
- The default container command runs the Release executable, `blood_flow`.
  The Debug executable is available as `blood_flow_debug`.

The release image is `ghcr.io/luca-heltai/metric-flow-x:v1.1.0`. This GitHub
release includes `run_container.sh`, `container-image.txt` and
`container-SHA256SUMS`. The launcher uses the digest of the tested
multi-architecture image.

See [container execution](https://luca-heltai.github.io/metric-flow-x/containers.html)
for launcher usage and CMake SDK access.
