# MetricFlowX 1.0.0

Released on 29 October 2026. This is the first stable release of MetricFlowX,
accompanying the arXiv preprint by Raksha Devi, Luca Heltai and Lucas O.
Müller, *An HDG-type discretization of 1D embedded blood flow in complex
networks with Riemann-coupled junctions*.

The preprint is available as [arXiv:2610.40080](https://arxiv.org/abs/2610.40080)
(submitted on 29 October 2026), with DOI
[10.48550/arXiv.2610.40080](https://doi.org/10.48550/arXiv.2610.40080).

## Software and reproducibility

- MPI-parallel C++ library and standalone `blood_flow` executable using deal.II.
- Implicit DG/HDG discretization of one-dimensional blood flow on embedded
  vascular networks, with Riemann-coupled junctions and RCR terminal models.
- Adaptive BDF time integration through SUNDIALS IDA, analytic linearizations,
  and PETSc or Trilinos linear-algebra backends.
- Canonical paper inputs, pinned datasets, output collection and scaling
  campaigns with recorded build and run provenance.
- Slurm-integrated OpenMPI launching that preserves the CPU affinity assigned
  by the cluster, preventing concurrent jobs from rebinding to the same cores.

The website's manuscript figures retain their original provenance. They are
archived results, not newly computed validation of this release.

## Container image

The release workflow tests native Linux AMD64 and ARM64 builds before
publishing `ghcr.io/luca-heltai/metric-flow-x:1.0.0` and the aliases `v1.0.0`,
`1.0`, `1` and `latest`. The image includes the executable, library, headers,
CMake package and matching deal.II SDK. AMD64 also undergoes Podman and
Apptainer checks.

The GitHub release provides `run_container.sh`, `container-image.txt` and
`container-SHA256SUMS`. The launcher embeds the immutable multi-architecture
image digest. Use that digest and retain the dataset and parameter snapshots
for reproducible runs.

```bash
curl --fail --location \
  https://github.com/luca-heltai/metric-flow-x/releases/download/v1.0.0/run_container.sh \
  --output run_container.sh
bash run_container.sh --workdir /path/to/case parameters.prm
```

See [container execution](https://luca-heltai.github.io/metric-flow-x/containers.html),
[paper reproduction](https://luca-heltai.github.io/metric-flow-x/reproducibility.html)
and [references](https://luca-heltai.github.io/metric-flow-x/references.html).
